# aochat helper (browser extension)

Adds a **Send to aochat** button on AO3 skin pages. Press it and the skin opens in
aochat, converted into a theme. It only acts when you press the button, only on
`archiveofourown.org/skins/*` and the aochat page, and sends nothing anywhere else.

## Install (Chrome, Edge, Brave)
1. Download this `extension` folder.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Press **Load unpacked** and choose the folder.

Then open any skin on AO3 (for example `archiveofourown.org/skins/929`) and press
**Send to aochat**.
