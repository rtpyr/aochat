# aochat helper (browser extension)

Two small helpers, both only when you press a button:

- **AO3 → aochat.** On an AO3 skin page, **Send to aochat** opens the skin in aochat,
  converted into a theme.
- **aochat → AO3.** On aochat's Code tab, **Send CSS to AO3** opens AO3's new *work skin*
  form with the CSS filled in, and **Send HTML to AO3** opens the new work page with the
  chat HTML filled into the text box (it switches the box to HTML mode if needed).
  It only fills the fields. You name the skin, press Create, pick the skin on your work and
  press Post yourself. You need to be signed in to AO3.

It only runs on `archiveofourown.org` skin and work pages and on the aochat page at
`rtpyr.github.io/aochat`, and sends nothing anywhere else.

## Install (Chrome, Edge, Brave)
1. Download this `extension` folder.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Press **Load unpacked** and choose the folder.
4. After updating the files, press the reload icon on the extension's card.
